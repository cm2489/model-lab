# Model Lab

Hands-on labs for customizing open-weight language models: run one, test it, fine-tune it, serve it, and write up what the numbers say.

Each lab ends in something public. The work is done on a 2021 MacBook Pro (M1 Max, 32 GB) plus a few dollars of rented compute.
